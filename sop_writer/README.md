# SOP Studio

用于快速制作操作说明的本地 Windows 桌面工具。Python 3.13 + PySide6。

## 启动

双击 `start.bat`，或者在本目录运行：

```powershell
.\.venv\Scripts\python.exe main.py
```

首次安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

只依赖 PySide6-Essentials，无需 Office、浏览器、PDF 打印机或在线服务。

可通过「文件 → 打开」加载 `examples/快速上手.sopx`，查看一份两页的可编辑示例。

## 截图 → 标注 → 文档

1. 默认按 **Ctrl+1** 全局截图，主窗口会暂时隐藏。拖动框选区域，Esc / 右键取消。
2. 截图显示在置顶悬浮窗中，**工具位于图片下方**。支持箭头、文本框、马赛克、曲线涂鸦、矩形，以及颜色、粗细、字号和撤销/重做。
3. 点击「插入画布」或按 **Ctrl+Enter**。图片按比例缩小到页面内；当前页剩余空间不足时自动插入新页。
4. 在文档中拖动元素，拖右下角缩放。图片默认保持比例，按住 Shift 可自由缩放；右侧可以精确输入坐标、尺寸、居中和调整图层。
5. 添加文本框后直接输入，**双击文字**再次编辑；Ctrl+Enter / Esc / 点击外部完成编辑。双击图片可追加标注。
6. **Ctrl+S** 保存为 `.sopx`；**Ctrl+E** 导出多页 PDF。

「设置 → 截图快捷键」可以修改全局组合键。若组合键被占用，状态栏会提示，可更换组合键或直接点击截图按钮。程序需要保持运行，最小化时也能截图。

## 画布和页面

- 所有页面纵向连续排列，左侧缩略图跳转，当前页可复制、删除、上下移动。
- 新建文档和「页面尺寸」支持 160～12000 像素，提供常用比例预设；不同页面可以使用不同尺寸。修改尺寸会改变页面边界，已有元素保持原位置和尺寸，超出边界的部分会裁切。
- 支持文件选择、拖入图片、Ctrl+V 粘贴剪贴板图片或文字，按图片 EXIF 自动旋转。
- Ctrl+滚轮缩放，空格+拖动或鼠标中键平移，方向键微调 1 像素，Shift+方向键微调 10 像素。
- Ctrl+D 复制元素，Ctrl+C / Ctrl+V 复制粘贴，Delete 删除；文档编辑支持最多 100 步撤销。

## 文件和导出

`.sopx` 是带版本信息的 ZIP 包，包含 `document.json` 和按 SHA-256 去重的内嵌 PNG 图片。保存采用同目录临时文件加原子替换，不依赖原始图片路径。可直接将文件复制到另一台安装此工具的电脑。

PDF 使用与画布相同的文字布局和图像尺寸，文字以文本绘制，图片保持导入分辨率；每页尺寸按 **96 DPI** 换算。例如 960×1360 像素对应约 254×359.8 mm。只导出纸张内容，不含选框、页面标签和界面。导出 PDF 后仍需保存 `.sopx` 以便后续编辑。

每 30 秒在 `%LOCALAPPDATA%\LocalTools\SOP Studio\recovery.sopx` 写入未保存文档的恢复副本（正在输入文字时顺延）。异常退出后下次启动会询问恢复。正常保存或确认放弃退出会清理副本。运行错误记录在本目录 `logs/sop-studio.log`。

当前版本中，截图标注在插入时合并为 PNG，箭头等不作为独立图层保存；追加标注可以在本次标注窗口中撤销，文档中的整张图片替换也可以撤销。多显示器截图使用 Qt 逻辑坐标合成，混合缩放显示器按最高缩放比例输出，低缩放屏的部分会相应放大。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用离屏 Qt 窗口，不会触发真实截屏或注册全局快捷键。覆盖保存恢复、损坏文件处理、标注绘制、画布交互、撤销重做和不同尺寸的 PDF 页面。真实系统快捷键、跨屏框选和混合 DPI 的实际桌面行为还需在目标显示器上操作确认。
