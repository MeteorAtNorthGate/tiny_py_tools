# SOP Studio

用于快速制作操作说明的本地 Windows 桌面工具。Python 3.13 + PySide6。

## 启动

双击 `start.bat`，或者在本目录运行：

```powershell
.\.venv\Scripts\python.exe main.py
```

首次安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

只依赖 PySide6-Essentials，无需 Office、浏览器、PDF 打印机或在线服务。

可通过「文件 → 打开」加载 `examples/快速上手.sopx`，查看一份两页的可编辑示例。

## 截图 → 标注 → 文档

1. 保持本工具运行，直接按 **Win+Shift+S** 使用 Windows 自带的截图工具。屏幕选择、多屏、分辨率与缩放交由 Windows 处理；Esc 取消。
2. 截图写入剪贴板后，自动打开置顶悬浮标注窗，**工具位于图片下方**。支持箭头、文本框、马赛克、曲线涂鸦、矩形，以及颜色、粗细、字号和撤销/重做。
3. 点击「插入画布」或按 **Ctrl+Enter**。图片按比例缩小到页面内；当前页剩余空间不足时自动插入新页。
4. 在文档中拖动元素，拖右下角缩放。图片默认保持比例，按住 Shift 可自由缩放；右侧可以精确输入坐标、尺寸、居中和调整图层。
5. 添加文本框后直接输入，**双击文字**或选中后按 **Enter / F2** 再次编辑；Ctrl+Enter / Esc / 点击外部完成编辑。双击图片可追加标注。
6. **Ctrl+S** 保存为 `.sopx`；**Ctrl+E** 导出多页 PDF。

标注窗口采用无边框布局，截图贴合上、左、右边缘，工具栏紧贴下方。图标按钮支持悬停提示；下排可直接选择常用颜色，通过两个滑块分别调整线宽与字号。线宽为 **1～50 px**，字号为 **6～80 px**，均采用指数刻度，让较小数值占据更多拖动空间；点击选中滑块后，**← / → 每次微调 1 px**，右侧显示当前值。马赛克与涂鸦一样沿自由轨迹涂抹，线宽决定笔刷直径，单击也能涂一个圆点。小截图的工具栏自动折行，长截图可以滚轮上下查看。拖动工具栏空白处、按住空格拖动图片，或用鼠标中键拖动图片来移动窗口；Ctrl+滚轮按比例缩放窗口，点击右下角「适应屏幕」恢复合适的预览窗口大小（原来此处显示缩放百分比）。右侧叉号 / Esc 取消，蓝色按钮 / Ctrl+Enter 插入。

工具栏在普通箭头（**A**）与涂鸦（**P**）之间提供**渐尖箭头（B）**：实心宽箭头头部，箭身向尾部逐渐收尖，颜色与线宽沿用当前设置。文本标注（**T**）直接在截图内编辑：**单击创建**保留原有初始尺寸，输入超出初始宽度后向右延长，不自动换行；**拖动创建**先显示文本框描边，松开后在框内输入，按拖出的宽度自动换行。文字行距为 1.2 倍字体高度。两种方式均支持 **Enter 确认、Shift+Enter 手动换行、Esc 取消当前文本**。支持中文输入法；输入期间暂停字母工具快捷键。点击「插入画布」会先确认正在输入的文本，再输出图片。

工具栏左端的**选择（V）**可以选中已完成的箭头、文本框、涂鸦、矩形或马赛克，蓝色虚线标示所选标记；点击空白处或切换绘制工具会取消选择。选中标记后，可直接用下排滑块调整它的线宽；选中文本框时，右侧字号滑块会显示出来，调整字号时文本框会随文字内容同步调整大小。仅在选择工具中选中标记后，**Delete / Backspace** 才删除整个标记；文本输入时仍用于删除字符。删除支持 **Ctrl+Z / Ctrl+Y** 撤销重做，保留原图层顺序。选择功能不提供移动或缩放；选框不会出现在插入的图片中。

**Ctrl+1** 和「系统截图」按钮也会打开同一个 Windows 截图界面，主窗口暂时隐藏。程序等原快捷键松开后，通过 `ms-screenclip://?source=HotKey` 启动截图，不再模拟发送 Win+Shift+S。额外快捷键可在「设置 → 截图快捷键」中修改；Win+Shift+S 始终由系统处理，无需注册到本工具。主窗口最小化、在其他应用中工作时也能自动接收截图。

两种快捷键都会检查系统截图界面是否实际出现。2 秒内没有响应时，只清理当前 Windows 会话中、没有可见截图窗口的系统 `ScreenClippingHost.exe` 残留进程，手动启动 Windows 截图工具以唤醒组件，然后自动重试一次。仍未出现截图界面时，已打开的截图工具可作为手动兜底（点击「新建」）；工具本身也无法打开时，结束等待、恢复主窗口并显示错误。恢复过程不会关闭可见的截图窗口；截图接收、Esc 取消、超时或退出都会停止后续重试与计时器。

程序只在检测到截图快捷键之后等待剪贴板中的新图片，不会读取启动前已有的图片，也不会在普通复制图片时自动弹窗；不会清空剪贴板。Esc 会取消等待，60 秒未收到新图片则结束等待。剪贴板短暂被占用或图片格式延迟提供时会重试，每次截图只接收一次。截图工具自身需要正常将截图复制到剪贴板。

「设置 → 自动接收 Win+Shift+S 截图」可以关闭自动接收。**Ctrl+Shift+V** /「插入 → 标注剪贴板图片」可手动打开标注窗，也适用于从其他截图软件复制的图片。连续截图时，当前标注保留，后续截图会排队，在当前图片插入或取消后逐张打开。

## 画布和页面

- 所有页面纵向连续排列。**Ctrl+M** 在当前页之后新增同尺寸页面。
- 当前编辑页作为内部状态维护，不自动显示蓝框。**单击左侧缩略图**才显式选择页面并跳转，蓝框用于标示页面操作对象；点击画布、点击页面列表空白处或在列表中按 Esc 取消显式选择，当前编辑页仍保留。
- 选中页面后，**Ctrl+C / Ctrl+V** 复制粘贴整页，**Delete** 删除页面，**上下拖动缩略图**调整页序；左侧右键菜单也提供新增、复制、粘贴和删除。复制保留尺寸、全部元素、样式和图片，可在本窗口切换文档后粘贴；粘贴的页面与元素使用新的标识。所有页面操作支持撤销，删除最后一页会清空内容并保留一个页面。
- 新建文档和「页面尺寸」支持 160～12000 像素，提供常用比例预设；不同页面可以使用不同尺寸。修改尺寸会改变页面边界，已有元素保持原位置和尺寸，超出边界的部分会裁切。
- 支持文件选择、拖入图片、Ctrl+V 粘贴剪贴板图片或文字，按图片 EXIF 自动旋转。
- Ctrl+滚轮缩放，空格+拖动或鼠标中键平移，方向键微调 1 像素，Shift+方向键微调 10 像素。
- Ctrl+J 复制元素，Ctrl+C / Ctrl+V 复制粘贴，Delete 删除；文档编辑支持最多 100 步撤销。
- 右侧坐标、尺寸、字号、描边宽度与不透明度均直接输入数值，不含步进箭头；滚轮用于滚动属性栏。字体下拉框保留，并使用细线箭头。拖动右栏左边界可调整宽度，最大为 **640 px**；属性表单会随宽度换行。
- 文字与文本框分组设置：**文本颜色、文本描边颜色、描边位置（向外 / 居中 / 向内）、文本不透明度、文本框填充色、文本框描边色、文本框不透明度**。文字行距为 1.2 倍字体高度。两种描边均可设置 0～50 px 宽度；不透明度为 0～100%，文字及其描边、文本框填充及其描边分别整体生效。
- 点击色块选择颜色，也可输入色值；清空色值或输入“无”可取消填充或描边。所有样式支持撤销、复制、`.sopx` 保存与 PDF 导出，旧文档会使用默认样式打开。

## 文件和导出

`.sopx` 是带版本信息的 ZIP 包，包含 `document.json` 和按 SHA-256 去重的内嵌 PNG 图片。保存采用同目录临时文件加原子替换，不依赖原始图片路径。可直接将文件复制到另一台安装此工具的电脑。

PDF 使用与画布相同的文字布局和图像尺寸，普通文字保留为文本，描边文字使用字形矢量轮廓；半透明描边文字以高分辨率图层合成，避免填充与描边交界处重复叠加不透明度。图片保持导入分辨率；每页尺寸按 **96 DPI** 换算。例如 960×1360 像素对应约 254×359.8 mm。只导出纸张内容，不含选框、页面标签和界面。导出 PDF 后仍需保存 `.sopx` 以便后续编辑。

每 30 秒在 `%LOCALAPPDATA%\LocalTools\SOP Studio\recovery.sopx` 写入未保存文档的恢复副本（正在输入文字时顺延）。异常退出后下次启动会询问恢复。正常保存或确认放弃退出会清理副本。运行错误记录在本目录 `logs/sop-studio.log`。

当前版本中，截图标注在插入时合并为 PNG，箭头等不作为独立图层保存；追加标注可以在本次标注窗口中撤销，文档中的整张图片替换也可以撤销。接收到的系统截图保持剪贴板图片的原始像素尺寸，不再自行拼接显示器画面或换算跨屏坐标。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用离屏 Qt 窗口和模拟剪贴板，不会触发真实截屏或注册全局快捷键。覆盖 Ctrl+1 消息分发与系统截图入口调用、界面未出现时唤醒与有限重试、恢复期间取消或收到截图、手动兜底、启动失败后窗口恢复、松键超时、系统快捷键识别、剪贴板新旧图片判断、取消与超时、重复通知、锁定重试、截图接收到标注插入的完整流程，以及文档保存、画布交互、撤销重做和 PDF 导出。Windows 原生键盘监听的安装和退出另行验证；实际系统截图界面仍需在目标桌面上操作确认。
